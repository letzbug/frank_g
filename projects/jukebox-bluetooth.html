Jukebox Bluetooth Project

A Bluetooth audio upgrade for classic jukeboxes that preserves the original record playback and automatically gives the jukebox priority whenever a record starts.

Overview

The Jukebox Bluetooth Project explores how modern wireless audio can be integrated into a classic jukebox without changing the character or normal operation of the original machine.

The goal is to allow music from a phone or another Bluetooth device to use the jukebox's existing loudspeakers whenever the machine is idle.

As soon as the jukebox begins playing a record, the system automatically switches the loudspeakers back to the original jukebox audio. Record playback always has priority.

Project details

The main challenge was to add Bluetooth functionality without requiring the user to operate additional switches or manually select between modern audio and the original jukebox.

A Raspberry Pi Zero acts as the central controller of the system. It handles Bluetooth audio and continuously monitors whether the original jukebox is producing an audio signal or entering its playback state.

When the jukebox is idle, the system routes Bluetooth audio to the existing loudspeaker installation. The jukebox can therefore be used like a normal Bluetooth speaker while keeping all of its original mechanical functions intact.

Once a record is selected and the jukebox starts playback, the controller detects this condition and activates the relay switching system. The Bluetooth source is disconnected and the original jukebox amplifier receives full priority.

After the record has finished and the original signal disappears, the system can return automatically to Bluetooth operation.

Bluetooth audio

Phones and other Bluetooth devices can use the original jukebox loudspeakers while the machine is not playing a record.

Automatic source switching

No manual selector is required. The system automatically changes between Bluetooth and the original jukebox audio.

Record priority

Whenever the jukebox begins playing a record, its original audio immediately receives priority over the Bluetooth source.

Line sensing

The controller monitors the jukebox audio or playback state to determine when the original machine is active.

Relay switching

Audio relays physically switch the loudspeaker path between the jukebox amplifier and the Bluetooth audio system.

Original hardware preserved

The concept is designed as an add-on so that the jukebox can continue to operate normally with records and its original controls.

Switching concept

The system operates around a simple priority rule: the original jukebox always wins.

During normal idle operation, the Raspberry Pi provides the Bluetooth source and the relay system connects this signal to the loudspeakers.

If a record is selected, the line-sensing logic detects the jukebox playback condition. The relays then switch the audio path back to the original amplifier.

This allows the upgrade to remain almost invisible to the user. Bluetooth is available when needed, but selecting a record automatically restores the traditional jukebox experience.

Technology

The project is based around a Raspberry Pi Zero combined with Bluetooth audio, signal sensing and a relay-controlled audio switching stage.

The Raspberry Pi manages the Bluetooth connection and the logic that determines which source should currently be connected to the loudspeakers.

A line-sensing circuit monitors the original jukebox signal. When activity is detected, the control system drives the relays so that the jukebox audio path is selected.

The concept is designed to be adaptable to different classic jukebox models while keeping the existing amplifier and speaker system in use.
