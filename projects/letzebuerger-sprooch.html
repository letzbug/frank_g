Lëtzebuerger Sprooch

A dedicated digital experience combining podcast content with selected UniPop courses around the Luxembourgish language and culture.

Overview

Lëtzebuerger Sprooch is a dedicated web experience created to bring together audio content and selected UniPop courses around the Luxembourgish language and culture.

The page provides a central place where visitors can listen to a featured podcast while also discovering related UniPop courses directly within the same experience.

Instead of separating editorial audio content and course promotion into different pages, the project combines both elements in one visual and interactive interface.

Project details

The goal was to create a standalone themed page that could be integrated into the existing UniPop website while allowing more freedom in layout, audio playback and course presentation than a standard WordPress content page.

The page is developed and hosted independently through GitHub Pages. It is then embedded into the UniPop WordPress website using an iframe.

This architecture makes it possible to design the complete experience independently while still presenting it as part of the official UniPop website.

A central element of the page is the integrated podcast. Visitors can listen directly to the audio content while additional sections present selected UniPop courses related to Luxembourgish language, culture and the topic of the featured episode.

Technology

The Lëtzebuerger Sprooch page is built as a standalone browser-based application using HTML, CSS and JavaScript.

GitHub Pages is used as the hosting platform, allowing the complete experience to remain independent from the main UniPop WordPress installation.

The finished page is embedded into WordPress through an iframe. This approach provides full control over the visual design, audio-player behaviour and interactive presentation while still making the experience accessible from the official UniPop website.

The page combines web-based audio playback with dynamic presentation of related course content and can be adapted for future themed productions.
